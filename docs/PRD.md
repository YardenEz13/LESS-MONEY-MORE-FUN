# PRD: Smart Benefits Recall (MVP)

> המסמך המקורי שממנו נבנה הפרויקט. `docs/ARCHITECTURE.md` מתאר את מה שנבנה בפועל
> ואת ההחלטות שהתקבלו בדרך.

## 1. תקציר מנהלים

מוצר מובייל שמטרתו להזכיר למשתמש בזמן אמת (Contextual Recall) על הטבות, הנחות
וגיפטקארדים שברשותו. המערכת מבוססת על הצהרת מועדונים ללא התחברות לחשבונות
(Zero-Auth), ומעבדת תקנוני הטבות ציבוריים באמצעות LLM לנתונים מותנים ומודרכים.

## 2. מטרות היעד ל-MVP

- **Zero Friction Onboarding**: משתמש מסיים הגדרת מועדונים בתוך פחות מ-60 שניות.
- **Recall בעולם הפיזי**: התראה מבוססת מיקום (Geofencing) בנקודות עניין מרכזיות
  בלבד (קניונים/מתחמים).
- **Recall בעולם הדיגיטלי**: תמיכה ב-Share Extension לדפדפן בנייד בקניות אונליין.
- **אמינות נתונים גבוהה**: הופעת תנאים מורכבים (Condition-awareness) ולא רק
  אחוזי הנחה שטחיים.

## 3. ארכיטקטורה וזרימת הנתונים

```
[Public Benefit Pages] ──> [Scraper Scheduled] ──> [LLM Extraction (Hebrew Prompt)]
                                                              │
                                                        Strict Schema
                                                              │
                                                    [Human Review / Threshold]
                                                              │
                                                         [Database]
```

1. **איסוף (Scraping)**: סריקה תקופתית של עמודי הטבות ציבוריים.
2. **עיבוד (Extraction Engine)**: הזרמת טקסט התקנון החופשי ל-LLM עם Strict JSON
   Schema המחלץ תנאים ספציפיים.
3. **סף בטחון (Confidence score)**: חילוץ ברמת בטחון נמוכה מועבר לתור בדיקה ידנית.

## 4. מפרט פיצ'רים ל-MVP

### א. Zero-Auth Onboarding

המשתמש מסמן ברשימה את כל המועדונים/כרטיסים שברשותו (ללא הזנת ת"ז או סיסמה).

- **כרטיסי אשראי**: ישראכרט, Max, כאל.
- **מועדוני מעסיקים/ארגונים**: חבר, קרנות השוטרים, בהצדעה, הייטקזון.
- **מועדוני קמעונאות**: שופרסל LIFE, סופר-פארם.

### ב. מנגנון Contextual Recall

1. **Geofencing חכם**: פוליגונים/רדיוסים סביב קניונים ומתחמי קניות מרכזיים —
   לא ברמת כל חנות בודדת ברחוב, למניעת עומס התראות. התראה מרוכזת בכניסה למתחם.
2. **Share Extension**: בעת גלישה באתר קניות נייד, המשתמש לוחץ Share → האפליקציה
   מזהה את הדומיין ומציגה את ההטבה המשתלמת ביותר עבורו באותו אתר.

### ג. כרטיסיית הטבה ותנאים

- סכום מינימום/מקסימום
- ימים ושעות
- ערוץ מימוש (אונליין / בסניפים)
- כפל מבצעים (כן/לא)
- תאריך אימות אחרון (`last_verified_at`)

## 6. מדדי הצלחה

1. **Ratio of Decision Impact**: לפחות 30% מההתראות שנשלחו הובילו לפתיחת הפירוט
   או לחיצה על "מימשתי".
2. **Zero False Positives on Conditions**: 0 דיווחים על משתמשים שהגיעו לקופה
   וגילו שהתנאים לא נכונים.
3. **Retention w1**: מעל 40% לאחר שבוע ראשון.
